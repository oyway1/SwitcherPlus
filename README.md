# סוויצ'ר פלוס

אפליקציית אנדרואיד לשליטה בשקע החכם של Switcher (וגם בדודים מדגם V2, V4 ו-Touch) ישירות דרך הרשת הביתית, בלי ענן.

## מה יש בה

- **כיבוי אוטומטי לכל זמן שתבחר**, גם 15 דקות או 5 (האפליקציה המקורית מאפשרת רק שעה ומעלה). אפשר לכוון בין דקה אחת ל-10 שעות.
- הכיבוי האוטומטי עובד **גם כשמדליקים מהכפתור הפיזי בשקע** או מהאפליקציה המקורית.
- כפתורי הדלקה מהירים ל-5, 15, 30 ו-60 דקות.
- "הדלק בלי הגבלה (חד-פעמי)": מדליק פעם אחת בלי כיבוי אוטומטי, וההגבלה חוזרת מהכיבוי הבא.
- צריכת חשמל בזמן אמת (וואט), ספירה לאחור עד הכיבוי, והיסטוריית אירועים.
- מוצאת את המכשירים לבד. לא צריך סיסמה, חשבון או מזהה מכשיר.

## איך עובד הכיבוי אחרי 15 דקות

השקע עצמו לא מקבל הגדרת כיבוי אוטומטי מתחת לשעה, אבל הוא כן מקבל פקודת "הדלק עם טיימר" לכל אורך זמן.
לכן כשהאפליקציה מזהה שהשקע דלוק בלי טיימר (או עם טיימר ארוך מדי), היא בודקת כמה זמן הוא כבר דולק ושולחת לו טיימר לזמן שנשאר.
מהרגע הזה **השקע עצמו** סופר לאחור ומכבה את עצמו, גם אם הטלפון יצא מהבית או נכבה.

התנאי היחיד: הטלפון צריך להיות על ה-Wi-Fi של הבית ברגע שהשקע נדלק, כדי שהאפליקציה תספיק לראות את זה (בדרך כלל תוך 5 עד 20 שניות).
בשביל זה האפליקציה מריצה שירות רקע עם התראה קבועה. בפתיחה הראשונה כדאי ללחוץ על "לאשר ריצה ברקע" כשהכפתור מופיע.

## בנייה והתקנה

### אפשרות א': GitHub (בלי להתקין כלום על המחשב)
1. צור repository חדש ב-GitHub והעלה אליו את כל התיקייה הזו.
2. בלשונית **Actions** תרוץ אוטומטית בנייה בשם "Build APK" (בערך 5 דקות).
3. בסיום, בתוך הריצה, הורד את `SwitcherPlus-apk` ותפתח את ה-zip.
4. העבר את קובץ ה-APK לטלפון והתקן אותו (צריך לאשר "התקנה ממקורות לא ידועים").

### אפשרות ב': Android Studio
1. פתח את התיקייה ב-Android Studio (File → Open).
2. חבר את הטלפון בכבל עם USB debugging פעיל ולחץ Run ▶.

## הערות

- אחרי ש-Android יאשר ריצה ברקע, האפליקציה צורכת קצת סוללה, כי היא מחזיקה את ה-Wi-Fi ער כדי לא לפספס הדלקה.
- מכשירים חדשים שדורשים token (Runner S11/S12, Light, Heater) לא נתמכים בגרסה הזו.
- אם הנתב משנה את כתובת ה-IP של השקע, האפליקציה מתעדכנת לבד מהשידורים שלו.
